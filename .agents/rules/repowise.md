This repository is indexed by Repowise (the `repowise` MCP server).
Before using `grep_search`, `find_by_name`, or `view_file` on unfamiliar code,
try `get_overview()`, `get_context(targets)`, or `search_codebase(query)` first—
they are more efficient and accurate than manual searching.
Before assessing impact, use `get_risk(targets)` or `get_change_risk(revspec)`.
If something appears to be a deliberate architectural decision, check `get_why()`.
If the answers seem outdated, point this out and suggest running `repowise update`.
