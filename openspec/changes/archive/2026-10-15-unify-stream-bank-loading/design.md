## Context

Audio engine asset loading was previously bifurcated: in-memory PCM sounds were managed through `BankManagerAdapter` and `AudioBufferLoader`, while streaming sounds were loaded individually through `audio.streams.load(soundId)` into a private `AudioEngine.#streamManifests` map.

Architectural boundaries across the layers:
- **Domain Layer**: `IBankManager` defines the lifecycle port (`loadBank`, `unloadBank`, `getBankState`). `ISpriteSoundManifest` defines sound resource locations and priority. `BankSystemRule` ensures sound completeness.
- **Infrastructure Layer**: `BankManagerAdapter` orchestrates bank loading; `AudioBufferLoader` handles decoding and RAM eviction of PCM buffers; `AudioUrlValidator` provides SSRF protection; `SoundController` requests buffers and stream manifests via injected resolvers.
- **Application Layer**: `AudioEngine` implements `IAudioEngine`, wiring infrastructure components.
- **Historical Constraints**: The 2026-09-06 chunked audio streaming architecture mandates a "near-zero RAM footprint" for streams: only manifest metadata is kept in memory prior to playback; audio chunks are fetched dynamically on-demand during playback by `ChunkedLoader`.

## Goals / Non-Goals

**Goals:**
- Unify asset loading under `BankManagerAdapter.loadBank()` so that calling a single bank load fetches both buffer sounds and stream manifests.
- Exclude stream manifests from `AudioBufferLoader` batch loading, avoiding invalid audio decoding and preserving buffer eviction quotas.
- Apply SSRF validation via `validateAudioUrl` to all stream manifest URLs before fetching.
- Aggregate progress and error events across buffer decodes and stream manifest downloads into a single unified telemetry flow.
- Cascade bank unloads to stop active `StreamInstance`s, clean up `EngineTicker` tasks, and evict cached manifests.
- Completely remove the legacy `audio.streams` public API from `IAudioEngine` and `AudioEngine`.

**Non-Goals:**
- Pre-fetching or pre-decoding stream audio chunks during bank loading. Chunk streaming remains strictly on-demand during playback.
- Altering the `IStreamManifest` schema or `StreamNode`/`ChunkedLoader` flip-flop scheduling mechanics.
- Modifying the Domain `IBankManager` interface signature.

## Decisions

### 1. Hybrid Stream Classification
**Decision**: In `BankManagerAdapter`, classify a sound as a streaming voice if `soundManifest[id].isStream === true` OR if the primary URL matches `/\.json($|\?)/`.
**Rationale**: Adding an optional `isStream?: boolean` to `ISpriteSoundManifest` provides explicit, strongly-typed classification for authors, while checking for `.json` preserves full backward compatibility with manifests generated by `packages/cli`.
**Alternatives considered**:
- *Pure file extension matching*: Fragile if manifest URLs use query parameters, redirects, or lack standard extensions.
- *Strict explicit property only*: Would break existing projects and CLI-generated sound manifests that do not include `isStream: true`.

### 2. Isolation of Stream Manifests from AudioBufferLoader
**Decision**: In `BankManagerAdapter.loadBank()`, partition bank sound entries before dispatching to loaders. Buffer entries are sent to `AudioBufferLoader.loadBatch()`. Stream entries are fetched directly via `fetch()` and stored in an internal `Map<string, IStreamManifest>` inside `BankManagerAdapter`.
**Rationale**: `AudioBufferLoader` executes `AudioContext.decodeAudioData()`, which rejects JSON payloads. Furthermore, `AudioBufferLoader` uses `precalculatedSizes` to reserve RAM against `ramQuotaMb`. Stream manifests are tiny JSON documents (~2–5 KB) and must not inflate buffer RAM quota reservations.
**Alternatives considered**:
- *Teaching AudioBufferLoader to load JSON*: Violates Single Responsibility Principle. `AudioBufferLoader` is specialized for audio buffer caching, LRU eviction, and Web Audio decoding.

### 3. SSRF Protection on Stream Manifest URLs
**Decision**: Validate all stream manifest URLs with `validateAudioUrl(url, this.loaderOptions)` before initiating network fetches. If validation fails, register the sound as a failure and dispatch an `onError` event.
**Rationale**: Protects against Server-Side Request Forgery (SSRF, CWE-918) and internal network probing (e.g., pointing a stream sound to `169.254.169.254` or internal microservices). Reuses the battle-tested validation logic already implemented in `AudioUrlValidator.ts`.

### 4. Manifest Resolution via BankManager Delegation
**Decision**: `BankManagerAdapter` provides `public getStreamManifest(url: string | readonly string[]): IStreamManifest | undefined`. In `AudioEngine.ts`, `manifestResolver` is wired as a delegate closure:
```typescript
const manifestResolver = (url: string | readonly string[]) => {
    return this.#bankManager.getStreamManifest(url);
};
```
**Rationale**: Encapsulates stream manifest storage inside the infrastructure adapter without leaking storage implementation to the Application or Domain layers. `SoundController` continues to receive its injected `manifestResolver` function without requiring knowledge of `BankManagerAdapter`.

### 5. Unified Progress and Atomic Error Semantics
**Decision**: Track loading progress with a shared completed count `loadedCount` across both loaders:
```
totalItems = bufferSounds.length + streamSounds.length
```
As each buffer sound or stream manifest completes, increment `loadedCount` and dispatch `this.events?.onProgress(loadedCount, totalItems, loadedCount / totalItems, lastKey)`. If any buffer or stream manifest fails, record the failure and transition bank state to `'ERROR'`.

### 6. Cascade Unload for Active Streams
**Decision**: In `BankManagerAdapter.unloadBank(bankId)`:
1. `router.stop(soundId, { allowTail: false })`: Stops both physical buffer voices and active `StreamInstance`s. Stopping a `StreamInstance` halts `StreamNode`, cancels its `EngineTicker` task, and disposes the instance.
2. `pool.purgeSound(soundId)`: Cleans pooled buffer voices.
3. `loader.purgeUrls(bufferUrls)`: Reclaims decoded PCM buffer RAM.
4. `streamManifests.delete(streamUrl)`: Evicts the stream manifest from memory.
5. Set state to `UNLOADED` and emit `onUnload(bankId)`.

### 7. Removal of Public `audio.streams` Surface
**Decision**: Delete `streams` from `IAudioEngine` and `AudioEngine`.
**Rationale**: Deepens the module boundary (Ousterhout style). Consumers interact purely with `audio.banks.load(bankId)` and `audio.banks.unload(bankId)`.

## Risks / Trade-offs

- **[Risk] Breaking API change for existing callers**
  - *Mitigation*: Update all unit tests (`AudioEngine.test.ts`), examples (`examples/main.ts`, `examples/audio-config/BankManifest.ts`), and documentation. Add `backgroundMain` to the `music` bank in example configs.
- **[Risk] Unhandled network race condition on concurrent `loadBank` calls**
  - *Mitigation*: `BankManagerAdapter` already gates on `getBankState(bankId) === 'LOADING' || 'LOADED'`. Store in-flight manifest fetch promises to guarantee single-flight semantics for concurrent calls.
- **[Risk] Stream sound assigned to multiple banks**
  - *Mitigation*: Existing `BankSystemRule` validation automatically validates all bank sounds against duplicate assignment across multiple banks.
